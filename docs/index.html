属性 Properties

实例化后可直接访问的只读属性。

list 属性 getter Station[]

获取车站全部列表，完整返回所有车站。

group 属性 getter Record<string, Station[]>

获取车站全部列表（按城市分组）。选择城市查看该城市下的所有车站。

方法 Methods

输入参数后点击查询（或按回车），查看实时调用结果。

find(keyword) 方法 Station[]

模糊搜索车站，匹配站名、拼音、拼音码、首字母、电报码、城市、城市编码等字段。

参数类型说明
keywordstring搜索关键词
findByName(name) 方法 Station | undefined

通过精确的车站名获取单个车站信息。

参数类型说明
namestring车站名（精确匹配）
findByTelecode(telecode) 方法 Station | undefined

通过电报码获取单个车站信息（大小写不敏感，内部转为大写匹配）。

参数类型说明
telecodestring电报码，如 BJP
findByPinyinCode(pinyinCode) 方法 Station[]

通过拼音码获取车站信息（大小写不敏感），返回匹配的列表。

参数类型说明
pinyinCodestring拼音码，如 bji
findByCity(city) 方法 Station[]

通过城市名或城市编码获取该城市下的所有车站。

参数类型说明
citystring城市名 / 城市编码
